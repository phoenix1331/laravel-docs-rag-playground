## Basic Routing

<a name="the-default-route-files"></a>
### The Default Route Files

All Laravel routes are defined in your route files, which are located in the routes directory. These files are automatically loaded by Laravel using the configuration in your bootstrap/app.php file.

<a name="redirect-routes"></a>
### Redirect Routes

Use Route::redirect.

<a name="route-parameters"></a>
## Route Parameters

Sometimes you will need to capture segments of the URI within your route. For example, you may need to capture a user's ID from the URL by defining route parameters in braces.

### Optional Parameters
